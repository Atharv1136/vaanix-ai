# Codebase Structure

**Analysis Date:** 2026-07-18

## Directory Layout

```
campusconnect-ai-assistant/
├── .agents/                 # GSD Core skills, workflows, and configs
├── .planning/               # Living project memory, roadmap, and codebase docs
│   └── codebase/            # Codebase mapping documentation
├── public/                  # Public frontend assets
├── src/                     # Application source code
│   ├── components/          # Reusable UI component elements (shadcn/radix)
│   ├── hooks/               # React Custom hooks
│   ├── integrations/        # Client and Server Supabase APIs and Types
│   ├── lib/                 # Shared utilities and error logic
│   ├── routes/              # TanStack Router layouts and pages
│   │   ├── _authenticated/  # Authenticated console pages
│   │   ├── auth.tsx         # Auth logic/form container
│   │   └── index.tsx        # Loading/redirection page
│   ├── server.ts            # Start SSR entrypoint
│   ├── start.ts             # Client start instance
│   └── styles.css           # Global layout styles
├── package.json             # Build commands and dependency listings
└── vite.config.ts           # Bundler config
```

## Directory Purposes

**src/routes:**
- Nests pages using file-system routing.
- Protected workspace resides entirely in `_authenticated/`.

**src/integrations/supabase:**
- Types file `types.ts` is auto-generated by Supabase CLI and details database structure.
- `client.server.ts` exports `supabaseAdmin` for backend API bypass.

**src/components:**
- houses Radix-ui elements and customizable styled components.

## Naming Conventions

- **Files:** PascalCase for React components (`*.tsx`), camelCase or kebab-case for utilities, functions, and TS modules (`.ts`).
- **Routes:** kebab-case folder or file names defining path segments.
